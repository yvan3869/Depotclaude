# Plans deposes pour l'atelier

Un agent tiers depose ici ses fichiers de plans (`<nom>.yaml`) ; la page Atelier les liste et le
proprietaire les importe dans un projet. Format et marche a suivre : `docs/agents.md`, section
"Deposer des plans dans l'atelier" ; modele en cours : `server/jobs/modele.yaml`.

Les `.yaml` de ce dossier ne sont pas suivis par git.
